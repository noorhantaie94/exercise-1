# 🌍 AutoGIS - Exercise 1: Geometric Objects & Spatial Fundamentals

## 📌 Overview
This repository contains my solutions for **Exercise 1** of the **Automating GIS Processes (AutoGIS)** course. This exercise focuses on establishing a strong foundation in spatial data manipulation and vector geometry handling using Python.

## 🛠️ Key Skills & Concepts Demonstrated
- **Spatial Geometry Construction**: Creating `Point`, `LineString`, and `Polygon` objects using the `shapely` library.
- **Python Function Development**: Writing robust, reusable functions with custom input validation and error handling.
- **Attribute & Spatial Extraction**: Calculating spatial metrics such as bounding boxes, areas, and centroid coordinates.

## 💻 Technologies Used
- **Language**: Python 3
- **Libraries**: `shapely`
- **Environment**: Jupyter Notebook / VS Code
- **Version Control**: Git & GitHub

## 📁 File Structure
- `Exercise-1-problem-1-2.ipynb`: Implementation of basic point and line geometries creation.
- `Exercise-1-problem-3-4.ipynb`: Working with complex polygons and spatial calculations.
